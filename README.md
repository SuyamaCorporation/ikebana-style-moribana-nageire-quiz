# 生け花 盛り花・投げ入れスタイルクイズ

池坊・草月流・小原流の代表的な生け花スタイルを説明から4択で答えるクイズアプリ。スタイル識別・役枝問題・比率問題・花器問題の4モードで花道の知識を楽しく習得できる。役枝長さ計算機や流派比較表も付属。

## 機能
- 4つのクイズモード（スタイル識別・役枝問題・比率問題・花器問題）
- 池坊・草月流・小原流の8スタイルデータベース
- 役枝（真・副・体・流し・控え）の役割クイズ
- 花道用語集（15語・検索機能付き）
- 役枝長さ計算機（花器の高さ・幅を入力すると推奨寸法を計算）
- 3流派の横並び比較表
- 累計正解数のlocalStorage保存
